# Architecture decision records

Use a new numbered ADR for significant architecture or compatibility decisions. Include
status/date, owner authorization, factual context with source links, alternatives,
decision, consequences, security/compatibility impact and verification. Proposed ADRs
do not authorize implementation. Never invent reasons for historical changes.

[ADR 0001](0001-supervised-local-and-isolated-engineering.md) records the current
foundation governance decision. Historical technical rationale remains in the linked
V0.3–V0.6 architecture/release documents, not retroactively reclassified as new ADRs.

[ADR 0002](0002-enduring-instructions-and-dated-state.md) separates enduring instructions from dated state (D02).

[ADR 0003](0003-additive-requirement-planning.md) records additive V0.7 planning and conservative mapping evidence.

[ADR 0004](0004-owner-approved-professional-workflow-vision.md) records owner-approved future professional workflow requirements without expanding V0.7.
